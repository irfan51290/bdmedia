The Problem

Manually reviewing bank statements to understand spending is tedious and error-prone. Categories are inconsistent and patterns are invisible. I needed a way to get an instant, honest picture of where my money actually goes.

How It Works

  • User uploads a bank statement CSV or PDF
  • Claude AI reads and recategorises each transaction
  • Spending is grouped into logical categories (food, transport, subscriptions, etc.)
  • A clean visual breakdown is generated with charts and totals
  • Runs entirely locally — no data leaves your machine

What I Learned

Parsing unstructured financial data from different bank formats is harder than it looks. Teaching Claude to be consistent with categories across hundreds of transactions required careful prompt engineering and validation logic.

Built With Claude

My first end-to-end project built with Claude Code. The file parsing, AI classification pipeline, and chart rendering were all designed through conversation. Proved that a working financial tool could be shipped in one week with zero prior experience in data visualisation.
