The Problem

Existing trading dashboards are cluttered, slow, and built for professionals who already know what they're doing. I wanted a clean, fast dashboard that surfaces the signals that matter — without the noise.

How It Works

  • React frontend fetches live market data via a Python backend
  • Portfolio positions tracked with real-time P&L calculations
  • Claude AI generates plain-English market summaries and alerts
  • Custom component system built from scratch — no UI library
  • WebSocket connection for live price feeds without polling

What I Learned

Building a real-time data pipeline that stays consistent under rapid market changes. WebSocket management, component re-render optimisation, and keeping the AI summaries accurate without hallucinating were the hard parts.

Built With Claude

The most ambitious week — Claude Code designed the full stack from scratch: Python data layer, React component system, WebSocket integration, and the AI alerting pipeline. Six weeks of building had compounded into real capability.
